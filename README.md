# Application d'Analyse de Performance de Portefeuille

Application Streamlit permettant :

- Import Excel
- Calcul automatique des indicateurs de performance
- Analyse risque/rendement
- Calcul du Bêta
- Corrélation
- Tracking Error
- Information Ratio
- Sharpe Ratio
- Export Excel
- Visualisations dynamiques

## Installation

pip install -r requirements.txt

## Lancement

streamlit run app.py
